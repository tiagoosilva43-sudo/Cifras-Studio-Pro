# 🎵 Cifras Studio Pro

Editor profissional de cifras musicais com interface moderna e recursos avançados.

![Versão](https://img.shields.io/badge/versão-2.3-blue)
![Licença](https://img.shields.io/badge/licença-MIT-green)

## ✨ Funcionalidades

- Editor de cifras com reconhecimento automático de acordes
- **Suporte completo para acordes com 7M, 9M** (sétima maior, nona maior)
- Conversor inteligente de cifras tradicionais
- Correção automática de palavras cortadas entre acordes
- Organização visual com cores personalizadas
- Transposição de tom automática com animação suave
- Exportação para PDF em formato A4
- Salvar e carregar projetos
- Modo escuro automático
- Interface drag-and-drop
- Design profissional com animações fluidas

## 🚀 Acesso

**Online:** [Cifras Studio Pro](https://tiagoosilva43-sudo.github.io/Cifras-Studio-Pro/)

**Local:** Abra o arquivo `index.html` no navegador

## 📖 Como Usar

1. **Dados da Música** - Preencha título, autor, tom e BPM
2. **Criar Seções** - Adicione versos, refrões e pontes com `[C] letra [G] aqui`
   - Use o **Conversor Automático** para transformar cifras tradicionais
3. **Organizar** - Arraste seções para definir a ordem de execução
4. **Exportar** - Gere PDF profissional ou salve o projeto

## 🎼 Acordes Suportados

O editor reconhece automaticamente:
- Acordes básicos: `C`, `D`, `E`, `F`, `G`, `A`, `B`
- Com sustenidos e bemóis: `C#`, `Db`, `F#`, `Bb`
- Tensões: `C7`, `D7M`, `E9M`, `Fm7`, `G13`, `Am11`
- Variações: `Csus4`, `Ddim`, `Eaug`, `Fmaj7`, `Gmin`
- Baixos invertidos: `C/G`, `D7/F#`, `Am/E`
