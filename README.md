# 🎵 Cifras Studio Pro

Editor profissional de cifras musicais com interface moderna e recursos avançados.

![Versão](https://img.shields.io/badge/versão-2.1-blue)
![Licença](https://img.shields.io/badge/licença-MIT-green)

## ✨ Funcionalidades

- Editor de cifras com reconhecimento automático de acordes
- Organização visual com cores personalizadas
- Transposição de tom automática
- Exportação para PDF
- Salvar e carregar projetos
- Modo escuro automático
- Conversor de cifras tradicionais
- Desktop/Mobile

## 🚀 Acesso

**Online:** [Cifras Studio Pro](https://tiagoosilva43-sudo.github.io/Cifras-Studio-Pro/)

**Local:** Abra o arquivo `index.html` no navegador

## 📖 Como Usar

1. **Dados da Música** - Preencha título, autor, tom e BPM
2. **Criar Seções** - Adicione versos, refrões e pontes com `[C] letra [G] aqui`
3. **Organizar** - Arraste seções para definir a ordem de execução
4. **Exportar** - Gere PDF profissional ou salve o projeto

## 💻 Tecnologias

HTML5 • CSS3 • JavaScript • SortableJS • jsPDF
