# Changelog

Todas as mudanças notáveis neste projeto serão documentadas neste arquivo.

## [2.3] - 2026-05-15

### Corrigido
- Suporte para acordes com **7M** e **9M** (sétima maior, nona maior)
- Regex de reconhecimento de acordes agora captura D7M, A7M, C9M, etc.
- Melhoria na detecção de linhas puras de acordes no conversor
- Correção no posicionamento de acordes durante conversão automática
- Melhor tratamento de cifras com acordes e letras misturados na mesma linha

### Melhorado
- Detecção mais inteligente de linhas de acordes vs. linhas de letra
- Conversor agora identifica corretamente quando uma linha tem menos de 10 caracteres após remover acordes

## [2.2] - 2026-05-12

### Adicionado
- Identidade visual profissional
- Animações fluidas na interface
- Rodapé com informações do projeto

### Melhorado
- Design geral da interface
- Experiência do usuário

## [2.1] - 2026-05-12

### Adicionado
- Reconhecimento automático de acordes consecutivos
- Espaçamento automático entre acordes adjacentes

### Corrigido
- Cor padrão do seletor agora é a primeira da paleta (#8a0000)

## [2.0] - 2026-05-10

### Adicionado
- Editor completo de cifras musicais
- Conversor de cifras tradicionais
- Transposição automática de tom
- Exportação para PDF
- Sistema de salvar/carregar projetos
- Modo escuro automático
- Interface drag-and-drop
- Organização visual com cores personalizadas
